# PointCloud Studio 使用説明書（v0.1.25）

[繁體中文](USER_GUIDE.zh-TW.md) · **日本語**

点群の表示・クリーニング・地形モデリングツール（英語・ダークテーマの UI）。MBES／LiDAR 測量データと海底ケーブル工事向け。
作成者：Mingyi Hsu（smingyi.hsu@gmail.com）

機能の流れ：XYZ/ASC/LAS/LAZ の読み込み → 3D 表示とカラースケール → 選択・Subset 編集・自動フィルタ → Reject（Class 7）／ゴミ箱（復元可、Undo/Redo）
→ TIN／DEM（Shoalest を含む）→ 断面、ケーブルルートと KP → 体積と多時期比較 → 土工設計（浚渫／整地／ケーブル用トレンチ）と勾配解析
→ 等深線（SHP / DXF 3D）→ 書き出し

> 画面上のメニュー名・ボタン名は英語のまま記載しています（例：**File → Export…**）。

## Windows 版のダウンロード
GitHub プロジェクトの **Releases** ページから `PointCloudStudio-windows.zip` をダウンロードし、展開して `PointCloudStudio.exe` を実行します
（Python のインストールは不要。初回起動で SmartScreen が表示されたら「詳細情報 → 実行」を選択）。

## macOS 版のダウンロード
**Releases** ページから DMG をダウンロードします：Apple Silicon（M シリーズ）は `…-macos-arm64.dmg`、Intel Mac は `…-macos-x86_64.dmg`
（対応する最低 macOS バージョンはビルド時のライブラリによります。Mac が古すぎる場合はアプリ起動時に必要なバージョンが表示されるので、その Mac 上で `bash build_mac.sh` を実行して自分でビルドしてください）。DMG を開き、PointCloudStudio を「アプリケーション」フォルダへドラッグします。

Apple の開発者署名がないため、初回起動時にブロックされます（「開けません」または「壊れています」と表示）。アプリを右クリック →「開く」→「開く」、
または「ターミナル」で一度だけ次を実行します：
```
xattr -cr /Applications/PointCloudStudio.app
```
Mac での操作の違い：ショートカットの Ctrl は ⌘（Command）に読み替えます。キーボードの delete キーで選択点を除外できます。
トラックパッドの 2 本指スワイプまたはピンチでズーム、Shift + ドラッグでパン。

## ソースコードから実行／インストール
```
pip install -r requirements.txt
```

**macOS ワンクリックセットアップ**：「ターミナル」でプロジェクトフォルダに移動し `bash setup_mac.sh` を実行します。Mac の環境を確認し、適切な Python 3.10–3.13 を探し
（見つからない場合は python.org の Python 3.12 を自動でダウンロード・インストール可能。macOS 標準の python3 は 3.9 で古すぎます）、`.venv` を作成して、
不足しているモジュールを順にインストールします：ビルド済みパッケージを優先し、ない場合のみソースからビルドします（必要に応じて Apple Command Line Tools のインストールを促します）。
オプションのモジュールがインストールできなくても他のモジュールは中断されません。完了すると **`PointCloud Studio.command`** が作成され、Finder でダブルクリックすると起動します。
後からいつでも再実行でき、不足分だけを追加インストールします。

どのプラットフォームでも `python core/deps.py check` で確認、`python core/deps.py install` で不足モジュールをインストールできます。
ソースから起動したときにモジュールが不足していると一覧が表示され、「Install」でまとめてインストールできます（完了後に再起動）。
オプションモジュールが必要な機能を使ったとき（例：rasterio がない状態で GeoTIFF を書き出す）にも同じインストール画面が表示されます。

## 起動
```
python main.py              # 空のウィンドウを開く
python main.py ファイル.laz   # ファイルを直接読み込む
```

## 基本操作
- ファイルを開く：Ctrl+O、またはファイルをウィンドウへドラッグ（.xyz .asc .txt .csv .pts .las .laz に対応）
- 回転：左ドラッグ；ズーム：右ドラッグまたはホイール；パン：Shift＋左ドラッグ
- 視点のショートカット：1 上面、2 正面、3 側面、4 斜め、F 全体表示

## 海域と陸域のデータ
- プログラム内部の Z は常に**標高（上向き正）**です。水深は負の値で表されます。画面表示は Depth（深さ、下向き正）に切り替えられます
- **Z が正の水深値のファイル**（水深 XYZ によくある形式）：XYZ 読み込みダイアログで「Z values are：Depth (down +)」を選ぶと自動で標高に変換されます。
  プレビューで Z がすべて正の場合は注意が表示されます。LAS、GeoTIFF などは Data パネルの ⋯ →「Z values are depths (flip sign)」で符号を反転でき、
  それに依存する TIN/DEM/等深線には Out of date が表示されます。設定はプロジェクトに保存されます。テキスト書き出しでは「Write Z as depth」で正の水深値として書き戻せます
- **海陸境界のデータ**（正負の値が混在）では自動的に **Topo-bathy** カラースケールを使用します：0 m 以下は青系、以上は緑～茶系で、境界は 0 m に固定されます。
  0 m の等高線（海岸線）はシアンで表示され、DXF では CONTOUR_ZERO 画層、SHP では TYPE が zero になります
- 土工設計と体積計算の基準面の高さ欄は、それぞれ Elevation／Depth を選択できます。自動フィルタの用語は「上方／下方」で表します
- **Reject 分類**（Subset パネル）：Class 7（低ノイズ）、Class 18（高ノイズ、LiDAR）または任意の分類。7、18 および使用した任意分類は
  除外済みとして扱われます（非表示、表示も可、Accept で元の分類に戻す）。LAS Point Format 0–5 は 0–31 の分類しか保存できず、超える場合は通知されます
- **分類による TIN／DEM の作成**：Create TIN／DEM の「Only classes」に分類（例：2 = 地表点）を入力すると、その分類だけで地形を作成します。
  ダイアログにはデータ中の分類と点数が表示され、作成したレイヤ名に分類が付きます
- **ほぐし率／締固め率**（Earthworks Design）：膨張係数（地山 → ほぐし土量、例：土 1.25、岩 1.5–1.7）、
  収縮係数（地山 → 締固め土量、例：0.90）。結果には掘削のほぐし土量、盛土に必要な地山土量と土量バランス（残土／不足）が加わり、CSV にも出力されます

## 読み込みと表示
- XYZ/ASC 読み込みダイアログ：文字コード（UTF-8／Big5）、区切り文字、開始行を自動判定。手動で調整し、列ごとに用途を指定できます
- LAS/LAZ の読み込み（元のヘッダと VLR を保持し、書き出し時に引き継ぎます）
- 3D 表示：標高／Intensity／RGB／Classification／単色による着色、点サイズ、Z 強調、表示上限による間引き
- バックグラウンドスレッドで読み込むため、大きなファイルでもウィンドウが固まりません

## 選択
- モード（ツールバーまたはショートカット）：V ナビゲーション、P 点選択、B 矩形選択、L 投げ縄
- Shift で追加、Ctrl で除外。Ctrl+A 全選択、Ctrl+I 反転、Esc で解除（描画中の Esc は描画の取り消し）
- 選択モードでは左ボタンは選択専用。ホイールズーム、右ドラッグズーム、中ボタンドラッグのパンは引き続き使えます
- 矩形選択／投げ縄は範囲内のすべての深さの点を選択し（貫通選択）、表示の間引きに関係なく全点で計算します
- 点選択はカーソルから 8 px 以内で最も手前の点を取ります
- 右側の Selection パネル：1 点のときは全項目を、複数点のときは範囲と属性の統計を表示。Copy でタブ区切りテキストとしてコピーできます

## 削除・ゴミ箱・元に戻す
- Delete / Backspace：選択した点をゴミ箱へ移動します。削除ごとに 1 つのバッチとして記録（番号、時刻、選択方法、点数）
- Trash パネル：バッチをクリックするとオレンジでプレビュー。「Show deleted points in view」で削除済みの全点を薄い赤で表示
- Restore（選択したバッチ）、Restore all、右クリックメニューで個別のバッチを完全削除
- Empty…：完全に空にします（確認あり）。完全削除した点は書き出されず、復元できず、Undo 履歴も消去されます
- Ctrl+Z / Ctrl+Y（または Ctrl+Shift+Z）：すべての削除と復元の操作を元に戻す／やり直す。削除を元に戻すと、その点は選択状態に戻ります

## 書き出し（File → Export…、Ctrl+E）
- 内容：有効な点（既定）、選択した点のみ、ゴミ箱のみ。ゴミ箱を *_trash ファイルとして別保存することもできます
- LAS/LAZ（元データが LAS）：元のヘッダ、Point Format、Scale/Offset、全フィールドと VLR（座標系を含む）をそのまま引き継ぎます
- LAS/LAZ（元データが XYZ）：LAS 1.2/1.4、座標の精度、EPSG（例：3826 = TWD97 TM2 121、pyproj が必要）を選択でき、独自フィールドは Extra Bytes として書き込みます。RGB がある場合は色を含む Point Format を自動選択し、0–255 の色は 16-bit に自動変換します
- テキストファイル：フィールドの選択とドラッグによる並べ替え、区切り文字、XYZ の小数桁数、ヘッダ出力の有無。既定では元ファイルの列順と区切り文字を使います
- バックグラウンドで実行し進捗を表示します。出力先が元ファイルと同じ場合は確認します
- 書き出していない編集があるとタイトルバーに ● が表示され、新規ファイルを開くときや終了時に通知されます

## カラースケール（カラーバーと高さ／深さの範囲）
- 「Color by」が Elevation または Intensity のとき（または TIN/DEM 表示時）、Color Scale カードと画面右側のカラーバーが表示されます
- **カラーバーの両端 = 固定された目盛り範囲**。Color Scale の Shallow / Deep（または Min / Max）だけで決まり、ドラッグしても変わりません
- **カラーバー上の 2 つのハンドル = 表示範囲**：色は 2 つのハンドルの間でのみ展開され、ハンドルの外側は端の色（Gray out の場合は灰色）
  - ハンドルのドラッグ：表示範囲の上限・下限を調整（目盛り範囲内に制限）
  - ハンドル間のドラッグ：範囲全体を移動。ホイール：カーソルを中心に表示範囲を拡大縮小。ダブルクリック：ハンドルを全目盛りに戻す
- Color Scale カードに現在の Display 範囲が表示され、「Reset」でハンドルを全目盛りに戻せます
- Shallow / Deep の入力：目盛り範囲を変更します。ハンドルが全目盛りだった場合は追従し、縮小されていたハンドル範囲は新しい目盛り内に制限されます
- Values as：Elevation（Z、上向き正）または Depth（−Z、下向き正）。データの Z がすべて ≤ 0 の場合は自動的に Depth になります
- Auto 2–98% / Full range：データに合わせて目盛りを再設定します（ハンドルも全目盛りに戻ります）
- Palette：Rainbow、Turbo、Viridis、Bathymetry、Grayscale（反転可）。Out of range：Clamp または Gray out

## TIN と DEM（Surface メニュー / Layers カード）
- Layers：点群、TIN、DEM をそれぞれ表示切替・透明度設定。⋯ メニューで書き出し、ワイヤーフレーム（TIN）、再作成、削除。陰影表示の切替も可能
- 表面作成後に点群を編集すると、レイヤに「Out of date」が表示され再作成を促します
- 表面は Elevation カラースケールで着色され、点群とカラーバー・Color Scale 設定を共有します
- Create TIN（Ctrl+T）：Delaunay 2.5D。最大辺長（データの空白を跨がないため）。事前にグリッド間引きも可能（実測点を保持：中央値 / 最浅 / 最深 / 最初の点）
- Create DEM（Ctrl+G）：グリッドサイズ。方法は Linear (TIN)、Mean、Median、Min Z、Max Z、Point count、IDW。
  既存の TIN の利用、小さな穴の補間、原点をグリッドに揃える設定が可能
- TIN の書き出し：LandXML、DXF 3DFACE、OBJ、PLY。DEM の書き出し：GeoTIFF（座標系付き）、ESRI ASCII Grid、XYZ グリッド点

### Shoalest depth (true position)
- 水路測量で一般的な浅所優先グリッド：各セルで「最も浅い 1 点の実測点」を残し、その実測点の真の X/Y（セル中心ではない）を記録します
- 平均・平滑化・移動を行わないため、最浅水深が平滑化で失われません。3D 表面はこれらの浅所の実位置を直接通ります
- Shoalest = Highest Z（Z 上向き、水深は負、既定）または Lowest Z（Z が正の水深。データの Z がすべて正の場合は自動選択）
- この方法は既定で穴を補間しません（実測でない水深を作らないため）。手動で有効にでき、補間したセルは XYZ 書き出しでセル中心として出力されます
- XYZ の書き出し：各浅所の真の座標を出力。GeoTIFF：セル値は各セルの最浅水深で、shoal_biased=true が付きます

## 断面ツール（Section、ショートカット S）
- Section モードに入っても**視点は変わりません**（どの角度でも描けます）。クリックで節点を追加、ダブルクリックまたは Enter で完了、Backspace で最後の点を削除、Esc で取り消し
- クリック位置は画面上に実際に見えている海底／表面上に置かれます（視線との交点を探索）。斜め視点や Z 強調時も正確です。
  描いた断面線、ポリゴン、Subset の枠、ルートはすべて地形に沿って表示されます
- 完成した断面線は節点をドラッグして修正でき、断面は自動で再計算されます。複数の断面を作成し、下部パネルで切り替えられます
- 下部の Section profile パネル：横軸は距離程（開始距離 Start を設定可能、例：KP のオフセット）、縦軸は標高または深さ（Depth モードに従う）
  - Width：回廊の半幅（± m）。この範囲内の点だけを表示
  - Points / TIN / DEM をそれぞれ表示切替。TIN の断面は三角網との厳密な交線で、データの空白では途切れます
  - V.exag 鉛直強調（または Shift+ホイール）。ホイールでズーム、ドラッグでパン、Fit で全体表示
  - Measure：2 点をクリックすると水平距離、高低差（深さの差）、斜距離、勾配（% と °）を表示
  - カーソル位置の距離程、Z／深さ、XY 座標をリアルタイム表示
  - CSV 書き出し（type, chainage, x, y, z, offset, point_index。点、TIN、DEM の 3 種を含む）と PNG 画像
- 点群の編集、TIN/DEM の再作成や削除の際に断面は自動更新されます

## プロジェクト構成（複数データ・座標系）
- **Open**（Ctrl+O）：新しいプロジェクトを開く。**Add Data**（Ctrl+Shift+O または複数ファイルのドラッグ）：現在のプロジェクトに点群や DEM を追加
- DEM の読み込みに対応：GeoTIFF、ESRI ASCII Grid（`ncols` で始まる .asc は自動でグリッドと判定）、規則的な XYZ グリッド（XYZ 読み込みダイアログで「DEM grid」を選択）
- **座標系**：プロジェクトの座標系は最初のデータで決まります。ファイルに座標系の記録がない場合は EPSG の選択画面が表示されます（コードまたは名称で検索可能。TWD97 TM2 121/119、TWD67、UTM 50N/51N、WGS84 を内蔵）
  - 後から追加したデータの座標系が異なる場合は、プロジェクトの座標系へ自動変換されます（点群は X/Y を変換、DEM は双線形で再サンプリング）
  - データが経緯度の場合は、プロジェクト座標系として投影座標系の選択を求められます
  - LAS の書き出しでは元ファイルの内容と元の座標系を引き継ぎます
- **Data パネル**：データごとに表示切替、透明度（DEM/TIN）、⋯ メニュー（Zoom to、Export、Wireframe、Remove）。DEM/TIN には元の点群が表示され、元の点群を編集すると「Out of date」が表示されます
- **DRAWINGS（画面上に描いた線と範囲）**：各断面線、体積／浚渫ポリゴン、現在の Subset 枠、確認済み範囲が Data パネルに一覧表示され、
  個別に表示を切り替えられます。⋯ メニューで断面図の表示、断面線の削除、ポリゴンの削除、確認済み範囲のクリアができます。表示状態とポリゴンはプロジェクトに保存されます
- 右側の **Navigation** 説明カードは ✕ で閉じるか、View → Navigation Help で切り替えます（設定は記憶されます）
- **編集のロック**：プロジェクトに点群が 1 つだけなら直接編集できます。点群が複数ある、または DEM しかない場合は自動でロックされ、点群行の **✎ Edit** で編集対象を指定します（一度に 1 つ）。点群ごとに選択、ゴミ箱、Undo 履歴を個別に保持します
- Create TIN / DEM：編集中の点群を元データとし（ロック中はどれを使うか確認）、結果はプロジェクトの新しいデータになります
- **プロジェクトの保存**（File → Save Project、Ctrl+S；Save Project As… Ctrl+Shift+S；Open で .pcsproj を直接開けます）
  - `.pcsproj`（JSON）に記録する内容：データのパス（絶対パスと相対パス）、座標系、読み込み設定、編集対象、断面、カラースケールと表示範囲、深さモード、Z 強調、点サイズ、視点
  - `<名前>.pcsproj_data\` に各点群の削除／ゴミ箱の記録と、作成した TIN、DEM を保存します（元データファイルは変更もコピーもしません）
  - 開くときは元ファイルを読み直して編集を適用します。ファイルが見つからない場合は場所を尋ねます。元ファイルの点数が変わっている場合はそのファイルの編集を適用せず警告します
  - 未保存の変更（編集、データの追加／削除、TIN/DEM、断面）がある場合、終了や新規プロジェクトの前に Save Project を促します
- 修正：LAS ファイルの RGB フィールドがすべて 0 の場合、既定で RGB（真っ黒）表示にせず、標高で着色するようにしました

## Subset エディタ（CARIS Bathy DataBASE / BASE Editor に類似）
- **Subset モード**（ツールバーの Subset または U キー）：3D 画面（任意の視点）で Subset の長軸をドラッグして描きます（任意の方向、例：ケーブル沿い）。幅は Subset パネルで設定します
- **Subset パネル**（下部）：
  - View：Along axis（長軸に沿った側面）／Across axis（長軸に直交する端面）
  - ツール：Pan、Box、Lasso。Shift で追加、Ctrl で除外。選択は 3D メイン画面に同期表示されます（メイン画面が 3D ビュー。Focus 3D で現在の Subset にズーム）
  - Reference surface：判断の目安として TIN / DEM の切断線も描画
  - ◀ Prev / Next ▶（PageUp / PageDown）：長軸に沿ってページ送り。Overlap で重なりの割合を設定
  - ✓ Mark complete（Ctrl+M）：確認済みとしてマークし、上面図に緑で表示。確認済み点数の割合を集計します
- **Reject**（Delete キー、Subset パネル、または選択カード）：
  - LAS / LAZ：既定では **Class 7（ノイズ）** としてマークし、削除しません。ゴミ箱へ移動する設定も可能
  - その他の形式：ゴミ箱へ移動
  - Class 7 の点は既定で非表示となり、選択・TIN/DEM・断面に使われません。「Show rejected (Class 7)」で赤く表示
  - **Accept**：選択した Class 7 の点を元の分類に戻します。すべての操作は Undo / Redo できます
- LAS/LAZ の書き出し：Class 7 の点は既定で分類付きのまま出力されます。「Exclude rejected points」で除外できます
- プロジェクトの保存時に、分類の変更、現在の Subset、確認済み範囲、Reject の設定も保存されます

## 自動フィルタ（Edit → Auto Filter…、Ctrl+F；Subset パネルの Filter…）
- フィルタの結果は「選択」になるだけで、自動では削除しません：プレビュー（Preview）→ 3D メイン画面／Subset エディタで確認 → Reject
- Cancel でダイアログを開く前の選択に戻ります。Keep selection で候補点を確認用に残します
- 方法（ユーザーが選択しパラメータを設定）：
  | 方法 | パラメータ | 用途 |
  |---|---|---|
  | Grid median deviation（MBES での第一候補） | グリッドサイズ、閾値（m または robust σ の倍数）、浅い側／深い側／両側のみマーク | スパイク |
  | Reference surface deviation | TIN/DEM、上方／下方の許容距離 | きれいな表面が既にある場合（基準面はクリーニング済みデータから作成すること） |
  | Statistical outlier (SOR) | 近傍点数 k、σ の倍数 | 高密度データ中の散在ノイズ |
  | Radius outlier | 探索半径、最小近傍点数 | 孤立点（高密度データ） |
  | Depth / elevation range | 最浅／最深（Depth モードでは正の深さで入力） | 明らかな異常値 |
- 対象範囲：全有効点、現在の選択、現在の Subset。結果は現在の選択を「置換」または「追加」できます
- Grid median はグリッドの中央値から中央値面を作って内挿し、セル内の海底勾配の影響を取り除きます。結果行にはデータのノイズレベル（robust σ）が閾値の目安として表示されます
- 既定のパラメータはデータの平均点間隔に応じて自動調整されます（グリッド ≈ 点間隔の 2.5 倍、探索半径 ≈ 点間隔の 3 倍）
- Reject 時、バッチ名に使用したフィルタ方法が記録されます（例：「Filter: Grid median deviation」）

## ケーブルルートと KP（File → Import Route…、Ctrl+R）
- 対応形式：
  - **Shapefile**（.shp）：ライン（各 part を 1 ルート）またはポイント（ファイル順に接続）。名称は NAME/ROUTE/CABLE/ID フィールドから取得。.prj があれば座標系を自動判定
  - **RPL CSV / TXT**：フィールド対応ダイアログ（XYZ 読み込みと同じ）。役割：Easting/Northing または Longitude/Latitude、KP、Route ID（1 ファイルに複数のケーブルを含められます）
- **読み込み時に座標系（EPSG）の確認が必須**です：.prj や経緯度フィールドがあれば事前に入力されますが、確認は必要です。プロジェクトと異なる場合はプロジェクトの座標系へ自動変換されます
- フィールドの自動判定：ヘッダ名を優先。ヘッダがない場合は「KP の増分 = 隣接座標間の距離」という幾何検査で KP と E/N 列を判定し、KP の単位（km / m）も判定します
- KP フィールドがない場合：KP = 開始 KP + ルートに沿った距離
- ルートはプロジェクトデータ（RTE）で、3D 画面ではシアンの線で表示され、整数 KP の位置にラベルが付きます
- Data パネルのルートの ⋯ メニュー：
  - **Section along route**：ルートを断面線とし、横軸にファイルの **KP（km）**（各頂点の KP から内挿）を直接表示。カーソルに KP を表示
  - **Subset editor along route**：Subset をルートに沿ってページ送りし、向きはルートの屈曲に従います。ステータスバーに現在の KP 範囲を表示
- Subset パネルに **Length**（Subset の長さ／ページ送りの大きさ）を追加
- レイアウト：Section profile と Subset editor は同じ領域のタブになりました。どちらも 1366 × 768 の画面で全体を表示できます

## 体積計算と多時期比較（Analysis メニュー）
### Volume / Difference（Ctrl+Shift+V）
- **A**（例：新しい時期の DEM/TIN）を **B**（別の表面、例：前の時期や設計面）または **基準面**（Elevation または Depth で入力、海域・陸域とも可）と比較
- 符号：**Δ = A − B**。正（赤）＝ A が B より高い：堆積／盛土。負（青）＝ A が B より低い：洗掘／切土
- 範囲：重なる領域全体、**ケーブルルート回廊**（ルート ± 半幅）、現在の Subset 枠、**ポリゴン**（3D 画面でクリックして描画、または Shapefile から読み込み。例：捨石の設計範囲。読み込み時に EPSG を確認）
- 結果：比較面積、**カバー率**、盛土／切土の体積と面積、正味体積、Δ の平均／標準偏差／極値／5%–95%、Δ のヒストグラム
- **カバー率が 100% 未満の場合は警告します**：どちらかの表面にデータがないセルは体積に含まれず、体積が過小になります。DEM の穴埋め、TIN から内挿した DEM、より大きなグリッドを使ってください
- 出力：**Add Δ layer**（A の形状で Δ により着色したレイヤ。プロジェクトに保存可能）、**Report CSV**、**Δ GeoTIFF**
### Point Cloud to Surface
- 編集中の点群の各点と選択した表面との高低差を「Δ to surface」カラースケール（青白赤、0 中心）で表示し、ステータスバーに統計を表示します
### 多時期断面
- 断面上に、表示中のすべての DEM/TIN（線）とその他の点群（点）を同時に描画します。データごとに色分けされ凡例が付きます。Surfaces / Other clouds で切り替え
- CSV 書き出しには各データの断面が含まれます

## 土工設計（Analysis → Earthworks Design、Ctrl+Shift+D）
**海域と陸域**の両方に対応：現況表面は海底でも地表でも構いません（DEM/TIN）。すべての高さ入力欄で
**Elevation（標高、上向き正）** または **Depth（深さ、下向き正）** を個別に選べ、画面の Depth 表示モードとは独立しています。
既定値はデータから判断し（すべて負の水深データは Depth、それ以外は Elevation）、切り替えると数値は同じ高さを表すよう自動換算され、
その基準での現況表面の範囲が参考として表示されます。
### Cut / fill（切土／盛土：浚渫、掘削、整地、築堤、埋戻し）
- 現況表面（DEM/TIN）＋設計範囲（ポリゴンの描画または SHP、ルート回廊、Subset 枠）
- 作業：設計高まで切盛（整地）／切土のみ（浚渫、掘削）／盛土のみ（盛土、道路盛土、埋立）
- 設計高（Elevation または Depth）。余掘り許容量（浚渫や掘削の余掘り。「余掘り込み」の切土量を別途報告）
- 法面：切土法面と盛土法面をそれぞれ **1 : n（鉛直 : 水平）** で設定し、設計範囲の縁から外側へ現況表面と交わるまで延ばします。0 = 鉛直壁
- 結果：設計範囲の面積、切土量（設計高／余掘り込み）、盛土量、正味量、法面を含む影響面積、最大掘削深／最大盛土高
### Trench（トレンチ断面：ケーブル、パイプライン、排水溝）
- ルートに沿った台形の溝：底幅、法面 1 : n、溝底＝「現況表面（海底または地表、中心線に沿って平滑化）からの深さ」または「設計高（Elevation または Depth）」
- 結果：総掘削量、平均断面積（平坦面での公称断面との比較）、最大掘削深、**KP 区間ごとの掘削量表**
- どちらの設計でも：Add layers（設計面＋切盛 Δ レイヤ。青＝切土、赤＝盛土）、Report CSV（パラメータと KP 表を含む。レポートの高さは常に上向き正）、Design / Δ GeoTIFF
### Slope Map（海底勾配）
- DEM/TIN から勾配（°）を計算し、Turbo カラースケールでレイヤを作成します。平均、95%、最大勾配と、閾値（既定 5°、10°、15°）を超える面積の割合を集計します
- 断面のカーソルには最初の表面レイヤの局所勾配（±2 m）も表示されます

## 等深線（Analysis → Contours…、Ctrl+Shift+C）
- 元データ：DEM または TIN（TIN は設定したグリッドで先に内挿）
- パラメータ：等深線間隔、基準値（等深線は 基準 + k × 間隔 に配置）、N 本ごとの計曲線（主曲線）、平滑化（グリッドのガウス平滑、単位：セル数）、簡略化（Douglas–Peucker の許容距離）、最小長（ノイズの小さな輪を除去）
- 等深線はプロジェクトのレイヤ（CNT）で、3D 画面では実際の深さに表示され（計曲線はより明るい）、計曲線の横に**深さの値**を表示します
  （計曲線がない場合はすべての等深線にラベル。Depth モードをオフにすると標高値）。プロジェクトに保存されます
- 書き出し（Data パネル ⋯ → Export）：
  - **Shapefile**：PolyLineZ、属性 ELEV（標高）、DEPTH（深さ、正の値）、TYPE（major / minor）、.prj 付き
  - **DXF**（R12）：各等深線は **3D ポリライン** で各頂点に Z 値を持ちます。計曲線と主曲線はそれぞれ CONTOUR_MAJOR / CONTOUR_MINOR 画層。閉じた等深線は閉じたポリラインとして出力
  - **DXF の深さラベル**：書き出し時に、計曲線のみ／すべて／なし、値（正の深さまたは標高）、小数桁数、文字高（m）、間隔（m）を選択します。
    文字は CONTOUR_LABEL 画層で等深線の高さに置かれ、等深線の向きに沿って回転し常に正立して読めます（ほぼ鉛直なものは下から上へ読む向き）。
    短すぎる小さな輪にはラベルを付けません。既定の文字高と間隔はデータ範囲から自動設定されます

## 点群分類（Edit → Classify Points…、Ctrl+K）
**ステップ 1：地表点の抽出**（いずれか 1 つ。パラメータ調整可、ダイアログに説明あり）
| アルゴリズム | 原理 | 用途 |
|---|---|---|
| SMRF（Pingel 2013） | 最低点グリッドに対し窓を段階的に広げたオープニング演算＋勾配閾値、最後に局所勾配で判定 | 汎用の第一候補（PDAL の既定方法） |
| PMF（Zhang 2003） | 窓を指数的に広げるモルフォロジーフィルタ。高低差の閾値は窓と勾配に応じて増加 | 平坦～中程度の起伏。急斜面では Slope を上げる |
| CSF（Zhang 2016） | 点群を上下反転し布を落とすシミュレーション。布に近い点が地表 | 急斜面・複雑な地形。大きな平屋根には硬め・粗めの布（3、2 m 以上） |
| Grid minimum | グリッド最低点を内挿して基準面とし、高低差閾値＋勾配補正 | 平坦または緩斜面、海浜、水深。グリッドは最大の地物より大きくすること |

**ステップ 2：地表より上（任意）**
- 植生：地上高により低（3）、中（4）、高（5）に分類。高さの閾値は調整可能
- 建物（6）：地上高が閾値を超え、局所的な表面粗さ（λ3 ⁄ Σλ）が小さく鉛直でない屋根点で、面積が閾値を超えるもの。屋根範囲内の壁面点も含みます

**その他**：対象範囲は全体／選択／Subset から選択。「未分類点（0／1）のみ変更」で手動分類を保持できます。分類全体を 1 回の Undo で戻せます。
完了後は自動で分類による着色になり、分類ごとの点数を表示します。XYZ など分類フィールドがないデータには分類フィールドが自動追加され、LAS 書き出し時に出力されます。

**合成地形での検証**（28 万点：起伏地形＋急斜面、樹木と低木 60 本、建物 3 棟。総誤差 = 誤分類点の割合）
| アルゴリズム | Type I | Type II | 総誤差 |
|---|---|---|---|
| SMRF | 0.00% | 1.29% | 0.31% |
| PMF（slope 0.6） | 0.72% | 0.36% | 0.63% |
| CSF（rigidness 3, 2 m） | 0.31% | 1.41% | — |
| Grid minimum（5 m） | 0.00% | 5.77% | 1.38% |
SMRF＋植生＋建物：地表 100%／99.6%（再現率／適合率）、植生 98%、建物 75%／92%（主な誤差は壁面と近接する樹木）。

## ベクタファイル（GIS／CAD）
これまで Shapefile を読み込めた箇所（ルート、構造物、体積計算の範囲ポリゴン）は、
**GeoPackage、GeoJSON、KML／KMZ、GPX、DXF**（ASCII）にも対応しました。複数のレイヤを持つファイル（GeoPackage のテーブル、KML のフォルダ、DXF の画層）はレイヤを選択します。
座標系はファイルから読み取り（.prj、GeoPackage の SRS。GeoJSON／KML／GPX は WGS84）、プロジェクト座標へ自動変換します。DXF には座標系がないため確認します。

**File → Import Vector Layer…**（Ctrl+Shift+L）、またはベクタファイルを直接開く／ドラッグすると、**ベクタ参照レイヤ**（境界、道路、禁止区域など）を追加でき、
3D では紫色で表示されます。Data パネルの ⋯ メニューで、ポリゴンを解析範囲（体積、土工、フィルタ）に設定、ラインをルートや中心線に変換、別形式で保存ができます。
解析結果の GIS 書き出しは任意の形式を選べます。GeoJSON と KML は仕様に従い常に WGS84 経緯度で出力します。

## 陸域解析（Land メニュー）
- **地形プロダクト**：勾配、斜面方位、曲率、粗さ（TRI）と面積統計。**地表モデル**：分類済み点群から DSM、DTM、nDSM（地物の高さ）、
  CHM（樹冠高）、樹冠被覆率と建物面積を作成（事前に点群分類が必要）。
- **変化検出**：2 時期の DEM の差分。2 時期の鉛直精度と信頼水準（68／95／99%）から検出可能閾値を設定し、閾値未満の変化は数えません。
  侵食・堆積の体積を集計（全域またはポリゴンごと）。調査日があれば年あたりの変化に換算します。**M3C2** は 2 時期の点群を地表の法線方向に沿って直接比較し、急斜面や崖面に適しています。
- **ストックパイル体積**：各ストックパイルの境界から底面を作り（境界の最適近似平面、境界の三角網、境界の最低点、または固定標高）、体積、面積、高さ、
  トン数（密度を入力）を計算します。多時期の調査では変化も一覧表示します。
- **道路線形**：中心線（ルートまたはベクタラインから変換）、計画縦断勾配（現況地形の平滑化または PVI 点）、幅員、横断勾配、切土・盛土の法面。
  設計面、切盛レイヤ、区間ごとの土量、土量累加曲線、縦断面を出力し、横断面も作成できます。
- **水文**：窪地の埋め、D8 流向と集水面積、河道網、指定した出口の集水域、指定水位での浸水範囲（特定の点と連結していることを条件にできます）。
- **離隔チェック**：指定分類の点（植生、建物）と 3D ライン（電線、パイプライン）との距離が限度未満の箇所を不足として、区間ごとにまとめ水平・鉛直成分を表示します。
  2D ラインには地上高を設定できます。

## 海底ケーブル解析（Lines & Structures メニュー、海域・陸域）

### ケーブル縦断（ケーブル天端高）
File → Import Route（または Cable & Foundations → Import Route）で SBI、TSS、ROV などのケーブル天端データを読み込むとき、フィールドを
**Cable top (elevation)**（標高、上向き正）または **Cable top (depth, + down)**（水深、下向き正。自動で標高に換算）に対応付けます。
調査会社の埋設深がファイルにある場合は **DoB (reported)** に対応付けて比較できます。Shapefile の PolyLineZ では「Z 値をケーブル天端とする」を選べます。
ケーブル天端高を持つルートをケーブル縦断と呼び、3D ではオレンジで実際の高さに表示され、断面パネルにもケーブル天端線が描かれます。

### ケーブル縦断読み込みの詳細設定
自動判定が正しくない場合は手動で設定できます：
- **CSV／TXT**：開始行、区切り文字（空白、タブ、カンマ、セミコロン、縦線 |）、列名の行、小数点のカンマ（21,50）、
  コメント記号（既定 #）。表の 1 行目で列ごとに役割を指定：東距／北距または経緯度、KP、ケーブル天端（標高または水深）、
  海底（標高または水深）、調査埋設深、路線名。経緯度は 10 進数または度分秒（例：N23°30'15.2"、120 30.5E）。
  海底と埋設深しかない場合は、ケーブル天端 = 海底 − 埋設深。「KP で並べ替え」を選べ、「Guess columns again」で再判定できます。
- **共通**：値の単位（m、cm、mm、ft）、高さ基準のシフト、値がケーブルの天端／中心／底のどれを表すか（ケーブル径で天端に換算）。
  列名に cm、centre などの文字があれば自動で設定されます。
- **GIS ファイル**：名称、KP、ケーブル位置（ジオメトリの Z または属性フィールド）、調査埋設深、海底のフィールドを自動で対応付け、個別に変更できます。ポイントレイヤ（例：
  SBI のケーブル天端点）は名称フィールドでケーブルごとに分け、KP 順に並べて縦断にします。

### Depth of Burial（Ctrl+Shift+B）
埋設深 DoB = 海底 − ケーブル天端（正の値は覆土あり）。海底には DEM、TIN、または点群（ルート両側 ± 回廊内の点の中央値）を使えます。
目標埋設深、サンプリング間隔、KP 区間を設定します。結果：不適合区間（開始・終了 KP、長さ、最小埋設深）、KP 区間ごとの統計と適合率、
露出長（DoB < 0）、調査埋設深との差。

### Free Spans
- **方法 A**（ケーブル縦断＋海底）：離隔 = ケーブル底（ケーブル天端 − ケーブル径）− 海底。
  > **注意**：海底の DEM／TIN は海底の点だけで作成してください。DEM を作る点群にケーブル自体の点が含まれていると（宙に浮いた区間のケーブルが「海底」として扱われる）、フリースパンでの離隔が小さく計算され、フリースパンが多数の小区間に分断されます。先に分類を行い、DEM 作成時の「Only classes」には海底（地表）分類 2 のみを指定してください。
- **方法 B**（点群のみ）：ルート ± 探索幅の中でケーブルの頂部を探し、海底は両側の点群の中央値をケーブル直下へ内挿します。
  回廊より狭い局所的な洗掘穴は見えないため、検出したフリースパンは断面ビューで確認してください。

離隔が最小離隔を超える連続区間をフリースパンとし、長さが報告閾値以上のものを SPAN、それより短いものを short と表示します。

### Rock Berm As-built
- **設計面**：テンプレート（天端幅、堤高、法面と端部の勾配。施工前の海底上に作り、堤天端高 = ルート中心線の海底 + 堤高）、
  または既存の設計面（例：GeoTIFF）を読み込みます。
- **照合**：厚さの差 = 施工後 − 設計。「設計 − 許容値」を下回るセルを不足とします。不足／過剰の面積と体積、カバー率、
  KP 区間ごとの設計量と実際の投入量、中心線上の堤天端の誤差を集計します。ルートにケーブル天端高がある場合は、捨石の被覆厚も計算し最小値と比較します。
- **Add layers** で設計面と差分レイヤを追加。**Add check sections** で一定間隔ごとに横断面を作成し、断面パネルで順に確認できます。

### Multi-year Cable Assessment（多年度ケーブル評価、Ctrl+Shift+Y）
複数年度の海底（実測またはシミュレーション予測）を同じケーブル縦断とまとめて比較します。
- **読み込み**：「Import yearly files…」で複数のファイル（GeoTIFF、ASC、XYZ、LAS など）を一度に選択すると、年はファイル名から自動で読み取られ
  （例：`seabed_2031.tif`、`pred2032_v2.xyz`）、シミュレーションデータかどうかを尋ねます。座標系と XYZ のフィールド対応は一度だけ尋ねます。
  年度表で年と「実測／シミュレーション」を変更できます。
- **年ごとの結果**：最小覆土、露出長、フリースパン（数、総延長、最長、最大離隔）、目標埋設深を下回る長さ、および
  **ジェット式埋設機（jetting trencher）による再埋設**に必要な長さ：覆土が「必要覆土」未満の位置はすべて再埋設が必要で、
  必要な沈降深さ = 必要覆土 − 現在の覆土。設定距離未満の間隔の区間は 1 回の作業にまとめます。埋設機の前進速度（m/h）を入力すると作業時間を見積もれます。
- **再埋設区間表**：区間ごとの最初に再埋設が必要な年、最初に露出する年、最初にフリースパンになる年。
- **グラフ**：年度ごとの傾向（シミュレーション年度は破線）、選択年度の KP に沿った海底／ケーブル天端／必要海底高と覆土。3D にはその年度の区間を表示します。
- **評価方法**：
  - **累積（既定）**：年度順に計算し、ある年に再埋設が必要になればその年に再埋設します（ケーブルを「再埋設後の覆土」まで下げ、埋設機の
    最大埋設深で制限）。以降の年度は下げた後のケーブル位置から計算を続けます。結果として再埋設年度、各作業（区間、沈降量、時間）、
    総延長と総時間、埋設機では到達できない区間（捨石やマットなどの別工法が必要）を表示します。
  - **独立**：毎年元のケーブル位置で計算し、「それまで何も対策しなかった」場合のその年の必要量を表します。
- **短すぎる区間の無視**：設定長より短い区間は再埋設に含めません（埋設機を動員する価値がないため）。
- **バッチ**：「Run for」で Batch を選び、複数のケーブル縦断にチェックを入れます（All／None／Invert あり）。GIS から読み込んだケーブルに連結フィールド（例：
  `cable_string`）がある場合、このフィールドで同じストリングのケーブルを端点の最短距離で連結し、連続したルートにできます。単独ケーブル、連結後のストリング全体、または両方を評価できます。
  バッチの一覧表に各項目の結果が表示され、行をダブルクリックするとその項目の詳細結果（グラフ、表、3D）が開きます。
- **年の範囲**：「Years from … to …」で範囲内のチェックした年度だけを評価します。
- **書き出し**：「Export Excel…」で複数シートの Excel ファイル（Summary、PerYear、Interventions、ReburialStretches、
  Segments、Points、Settings。openpyxl がない場合はシートごとの CSV）を作成します。「Export figures…」でケーブル／ストリングごとに 5 枚の図を作成します：
  年度傾向、各年の海底と最低包絡線、海底低下量と最小覆土、各年の再埋設後のケーブル位置、再埋設回数と初回の年。
- **前提**：ケーブルはたわまないものとするため、フリースパンの結果は安全側になります。

### 構造物と調査日
Cable & Foundations → **Import Structures…** で風車、変電所、杭位置を読み込みます：名称、座標、基礎径（CSV／TXT のフィールド対応、
または Shapefile のポイント。径のフィールドがない場合は既定値）。3D では基礎径の円と名称で表示します。
各点群と地形面には**調査日**を設定できます（Data パネル ⋯ → Survey date、または解析ウィンドウの表に直接入力。形式 YYYY-MM-DD）。
多時期解析は日付順に並べ、速度は年あたりで計算します。

### Scour Monitoring（洗掘モニタリング）
構造物ごとに基礎を中心とした局所グリッドを切り出し、洗掘深 = 基準高 − 海底（正 = 基準より低い）とします。基準は次から選べます：
- **遠方場**：同じ調査で、杭から杭径の 8–10 倍の環状帯の海底の中央値（倍数は調整可能）
- **基準面**：例えば施工前の調査
- **固定標高**

構造物・調査時期ごとの結果：最大洗掘深とその距離・方位、平均深さ、洗掘範囲（杭とつながり、深さが閾値を超える領域の最遠距離）、
洗掘面積と体積、前回からの変化と年あたりの速度。結果ウィンドウで構造物ごとの洗掘深図と放射状断面を確認でき、
深さレイヤの追加や、構造物ごとの洗掘深 GeoTIFF の書き出しができます。

### Sand Wave Migration（砂堆移動）
ルートに沿って各時期の海底をサンプリングし、まず長波長フィルタ（移動平均）で地域的な海底を分離し、残りを砂堆とします。ウィンドウごとに変位を計算します：
- **2D 地形照合**：速度と方向を求めます。峰線の長い砂堆では峰線に直交する成分のみを採用します（砂堆が実際に動く方向）
- **ルート沿いの断面**：ルート方向の変位のみを求めます

信頼性が不十分なウィンドウ（相関が低い、明確な砂堆がない、変位が探索上限に達した）は表示して除外します。
さらに最初と最後の時期の波峰位置を比較します。ケーブル縦断を選択すると、最後の時期の砂堆を観測されたルート方向の速度で移動させ、
年度ごとの埋設深、露出長、露出までの予想年数を推定し、露出リスクのある区間を一覧表示します。これは線形外挿による推定で、調査頻度の計画に適していますが、
実際の調査の代わりにはなりません。

### 結果と書き出し
結果ウィンドウには概要、KP に沿ったグラフ、区間表と KP 区間表があります（行をダブルクリックすると 3D の該当位置へ移動）。3D では色で表示します：
緑は適合、赤は不適合／フリースパン、オレンジは短いフリースパン、灰色はデータなし。
CSV の書き出しでは summary、segments、kp_bins、stations の 4 ファイルを作成します。Shapefile は属性付きの PolyLineZ の区間です。グラフは PNG で保存できます。

## 高度なフィルタと IHO S-44

### Auto filter に追加された方法
- **CUBE-style**：Calder & Mayer（2003）の原理に基づきます。各水深点の鉛直／水平不確かさを近くのグリッド節点に伝播させ、節点ごとに点を複数の深さ仮説（海底、魚群／水中ノイズ、多重反射…）に分けます。**Locale**（近傍の節点と整合、既定）、**Density**（点数が最多）、**Prior**（指定した TIN／DEM に最も近い）で海底の仮説を選び、それとの差が合成不確かさの k 倍を超える点を疑わしい点とします。CUBE 深さ、95 % 不確かさ、仮説数の 3 つのグリッドレイヤを追加できます。バッチ処理版のため、結果は CARIS／Qimera の CUBE と近いものの完全には一致しません。
- **IHO S-44 TVU test**：残差（局所中央値面または TIN／DEM に対する）がその等級の TVU 限度を超える点、または点自体の TPU が限度を超える点。
- **Robust local surface (MAD)**：近傍 k 点で平面を当てはめ（その点自身は含まない）、残差がロバストなばらつき（1.4826·MAD）の N 倍を超える点。斜面、砂堆、構造物付近ではグリッド中央値より安定します。
- **Isolated clusters**：ボクセルの連結でクラスタ化し、閾値より小さく主表面でないクラスタ（水中ノイズ、魚群、気泡、浮遊点）。
- **Photogrammetry noise**：支持する画像ペアが少なすぎる点（`views`）、局所表面に対する残差（許容値は距離の 2 乗に比例して拡大）、カメラ視線上の浮遊点（カメラの外部標定が必要）、空の色をした面外の点（RGB が必要）。カメラには Reconstruct で作成したカメラ CSV（X Y Z ω φ κ f 画像サイズ、主点）、またはカメラのベクタレイヤ（位置のみで、浮遊点チェックは不可）を使えます。

### 不確かさ（TPU／TVU／THU）の入力元
CUBE と S-44 で共通：点の属性フィールド（LAS extra bytes または XYZ の列。TPU、TVU、THU などは自動認識）、別の XYZ／CSV（平面位置で対応付け、最大距離を設定可能）、GeoTIFF／BAG グリッドの任意のバンド（双線形で取得）、IHO 等級モデル、固定値。値が 95 % 信頼水準（CARIS／Qimera の TPU）か 1σ かを指定します。値のない点は指定した IHO 等級モデルで補います（S-44 の a-priori チェックでは不適合とみなします）。

### Analysis → IHO S-44 Check
S-44 第 6.0.0 版に基づきます：TVU = √(a² + (b·d)²)、THU = c + p·d（95 %）。
- **A-priori**：各点の TPU を各等級の TVU／THU 限度と比較（適合率。S-44 では 95 % が要求されます）。
- **A-posteriori**：各点の基準面（局所中央値面または TIN／DEM）に対する残差を TVU 限度と比較。
- **Crosslines**：別の点群（交差測線）と主測線の中央値面との差の統計と適合率。
- **Coverage**：指定グリッド（既定はその等級の特徴物サイズ）でのカバー率と空白（holidays）。
- **特徴物検出**：「点密度がそのサイズを解像するのに十分か」の統計的な目安のみで、検出試験ではありません。
- 結果ウィンドウで限度超過の点を選択し、Excel／CSV レポートを書き出せます。「グリッドごとの適合率」と「カバー／空白」のレイヤも追加できます。結果は判断の補助であり、成果の認証を意味するものではありません。

## 海図プロダクト（Chart メニュー）
すべての海図プロダクトは「浅い側に寄せる」ことを原則とします：再サンプリング、座標変換、等深線の総描はいずれも水深を浅くするだけで、深くはしません。
- **Vertical Datum (to Chart Datum)…**：高さを測量基準（TWVD2001、平均海面など）から海図基準面（LAT、MLLW…）に変換します。分離量 S は「元の基準における海図基準面の高さ（上向き正）」で、例えば海図基準面が平均海面の 1.80 m 下なら S = −1.80 です。S は定数、グリッドファイル（GeoTIFF／ASC、双線形内挿）、点の表（X Y S、最近傍または逆距離加重）のいずれかで指定します。グリッドファイルの範囲外の点やセルは変換されず、その数が通知されます。グリッドは新しいレイヤになります。点群は新しいレイヤにするか、元のレイヤの高さを直接変更できます（メモリ節約。プロジェクトを開き直すと再適用されます。同じ点群への二重の変換は防止されます）。選択した S-100 の基準面コードがレイヤに記録されます。
- **Export Bathymetric Surface (S-102 / BAG)…**：
  - **IHO S-102 3.0.0**：水深＋不確かさ（HDF5）。座標は WGS 84／UTM に変換します（S-102 の規定。TWD97 は不可）。ファイル名は 102＋4 文字の作成者コード＋名称。書き出し後に GDAL の validate_s102 で自動チェックし、結果を表示します。
  - **BAG**：プロジェクト座標系で、ISO メタデータ（担当者、組織、概要、鉛直基準）付き。
  - 水深グリッドには「shoal」方法の DEM または CUBE グリッド（Shoal 判定）を使ってください。不確かさにはグリッド（CUBE の不確かさなど）、IHO S-44 等級の TVU、または定数を使えます。
- **Chart Layers…**：S-57 オブジェクト形式の海図レイヤ
  - **水深点 SOUNDG**：浅い順に選び、図上の最小間隔 = 縮尺 × 図上間隔（例：1:10,000、5 mm → 50 m）。省かれた水深点の近くには、必ず同じかより浅い水深点が残ります。VALSOU は 0.1 m 単位で浅い側に切り捨てます（12.37 → 12.3）。
  - **等深線 DEPCNT** と**水深区域 DEPARE**（DRVAL1／DRVAL2）：まずグリッドの近傍最大値を取り（浅い側）、総描後の等深線は深い側へしか移動しません。
  - プロジェクトにベクタレイヤとして追加し、SHP／GPKG／GeoJSON（オブジェクトごとに 1 ファイル）で書き出せます。
- CUBE フィルタに「Shoal」判定を追加：節点ごとに十分な水深点に支持された最も浅い仮説を採用します。航海用の水深面に適しています。

## 高精度地図（HD マップ）のアノテーション（HD Map メニュー）
- **点群の分類**：ASPRS 標準分類（11 路面、13、15、17）と 64–76 のユーザー定義分類（車線区画線、縁石、ポール、交通標識、信号機、ガードレール、横断歩道、停止線、路面標示、歩道、車両、歩行者、中央分離帯）を使います。矩形選択や投げ縄で選択した後、**Label Selected Points（Ctrl+Shift+K）** を押します（元に戻せます）。分類が 31 を超える LAS は書き出し時に自動で LAS 1.4（Point Format 6 以上）にアップグレードされ、GPS 時刻、反射強度、RGB、スキャン角などのフィールドはすべて保持されます。
- **Annotate（ショートカット A）**：点群上に車線区画線、縁石、道路境界、停止線、ガードレール、横断歩道、路面標示、ポール、標識、信号機を描きます。最も近い点にスナップでき、サブタイプ（実線／破線…）、色、幅、高さ、車線 ID を設定できます。クリックで頂点を追加、ダブルクリックまたは Enter で完了、Backspace で直前の点を削除、Esc で取り消し。ドラッグ（パン）では頂点は追加されません。
- **半自動抽出**：
  - **Extract Lane Markings**：路面点のうち局所的に明るい（反射強度の高い）点から区画線の縞を見つけ、方向に沿って実線または破線につなぎ、停止線（Stop line フィーチャ）も抽出します。路面分類（11）だけでなく、未分類のデータにも使えます（壁面、車両、標識、路面上に張り出した樹冠は「最低面」チェックで除外されます）。適用範囲：カーブ半径約 60 m 以上、点密度約 100–1000 点／m² 以上。遮蔽による 12 m 以内の欠落はつなぎ、実線は実線のまま判定します。二重線（ダブルイエロー）は 2 本に分けます。横断歩道と矢印はその他の標示（分類 72）とし、車線区画線は作成しません。点密度が約 100 点／m² 未満、半径約 60 m 未満のカーブ、または区画線が摩耗している区間は、手動のアノテーションで補ってください。
  - **Extract Poles**：地表より上の細長い鉛直の点群（事前に地表分類 2 が必要）。
  - 抽出した点には分類も設定されます（元に戻せます）。
- **Lanelet（車線）**：アノテーションパネルで左・右の境界線を選んで作成します（進行方向は左境界線の描画方向に従います）。制限速度を設定できます。
- **Export HD Map**：Lanelet2（OSM XML。経緯度と local_x／local_y を含み、lanelet2.io と Autoware で読み込めます）、または SHP／GPKG／GeoJSON（タイプごとに 1 ファイル）。

## ケーブル解析レポートと SHP（0.1.25）
- **Export report…**：書式設定済みの Excel（Summary はケーブルごとに 1 行で不適合を色付け、Stretches は露出／目標未達／フリースパンの各区間について KP、長さ、最悪値と開始・終了の E/N、KP bins、Settings）と、ケーブルごとに 1 枚の図を出力します。単独・バッチのどちらにも対応。
- **Export GIS…**：既定は SHP で、タイプごとに 1 ファイル（DoB：exposed、below_target、cable。フリースパン：free_span、short_span、span_max_gap の点）。バッチではすべてのケーブルを同じファイル群に書き込みます（CABLE フィールド）。多年度評価ではさらに exposed、free_span、reburial_needed（年ごと）、reburial_stretches、interventions を出力します。

## ケーブル解析（Cable analysis）のバッチ
- ウィンドウ上部の「Run for」で **Batch — several cables** を選び、ケーブルにチェックを入れて実行します：埋設深（DoB）またはフリースパン（方法 A：ケーブル天端高が必要。方法 B：任意のルート＋点群）をケーブルごとに解析し、KP 範囲はケーブル全体です。捨石の照合は捨石区間ごとに行い、バッチには対応しません。
- 結果の表に「Batch summary」（ケーブルごとに 1 行）が表示され、ケーブルをダブルクリックするとそのグラフ、区間、3D 表示が表示されます。
- **Export batch…**：Excel（Summary、Segments、ケーブル列付きの KP bins、設定、解析されなかったケーブル）と、ケーブルごとに 1 枚の図を出力します。

## 多年度ケーブル評価：ルールのオプションとリンクファイル
- **Export figures** は 00–05 に加え、年ごとの「ルート沿いの年度図」（海底、ケーブル、再埋設、覆土）を、ケーブル／ストリングごとのフォルダ（*_years）に出力します。単独・バッチとも同じです。
- **Link files (read when run)**：年ごとの海底グリッド（GeoTIFF／ASC…）はリンクのみ作成し、プロジェクトには読み込みません。評価の実行時にケーブル沿いの必要な範囲だけを読み込むため、数十年分のモデル結果でもメモリ不足を避けられます。ISBL／DSBL も「…」で単一ファイルをリンクできます。
- **ISBL（任意）**：図にのみ使うか、「Initial cable level」で「ISBL − required burial」を選びます：まずピークカット（切土のみで盛土なし、勾配上限あり）を行い、要求埋設深を差し引きます（砂堆区域：ISBL の勾配が設定値を超える、または ISBL − DSBL が設定値を超える区域。その他の区域は別の値）。この場合ルートにケーブル天端高は不要です。
- **Re-burial trigger**：覆土が閾値未満、または露出時（ケーブルが海底より高い）のみ。
- **Only continuous stretches of at least**：トリガー区間がこの長さ（例：7 m）以上連続した場合のみ再埋設します。
- **Short exposures settle**：上記の長さより短い露出（再埋設しないもの）は、累積モードでケーブルが海底面まで沈下したものとみなします。
- **Re-burial action**：指定した覆土で海底下に埋め戻す、またはケーブルを現在の位置から指定深さだけ下げる。
- **Re-burial cost**：メートルあたりの費用、割引率、基準年。年ごとの費用、現在価値、合計とバッチの概要。
- 元のプログラムとの相互照合：同じルールで、年ごとの再埋設長、各点の回数、維持後のケーブル高が一致することを確認しています。

## メモリ使用量
- **大きな LAS／LAZ（200 万点以上）**：チャンク単位で読み込み、座標と属性だけを保持して元のポイントレコードは保持しないため、メモリを約 40 % 節約します。LAS の書き出しやその他のフィールド（GPS time、リターン…）の書き出し時には元ファイルから再度ストリーム読み込みし、すべてのフィールドと変更した分類を保持します。そのため書き出し前に元ファイルが存在し、変更されていない必要があります（そうでない場合は XYZ での書き出しを提案します）。
- **大きなグリッド（5,000 万セル超）**：読み込み時にフル解像度、または ½、¼、⅛ 解像度（セル平均）を選べ、プロジェクトを開き直すと同じ設定を使います。
- **3D 表示**：400 万セルを超える DEM は間引いて表示します（n セルごとに 1 セル）。解析には完全なグリッドを使います。
- 点群の Display limit（Display パネル）で同時に表示する点数を決めます。メモリの少ないコンピュータでは下げてください。

## レイヤの色と文字ラベル
ルート、ベクタレイヤ（SHP／GPKG／GeoJSON／KML／DXF…）と構造物：Data パネルのそのレイヤの ⋯ メニュー → **Colour & Text Label…** で、線／記号の色と、3D ウィンドウに表示する文字フィールドを設定できます（ルート：名称または任意のルート属性、KP ラベルの切替。ベクタレイヤ：任意の属性を各フィーチャに表示。構造物：名称または径）。設定はプロジェクトに保存され、Data パネルのレイヤのラベルにその色が表示されます。

## グラフの背景（黒／白）
すべてのグラフと書き出す図（ケーブル、陸域、海底、多年度評価、断面）は黒背景または白背景を選べます：View → Chart Background、または各解析ウィンドウのグラフ上部の「Chart background」メニューで切り替えると、開いているすべてのグラフとその後に書き出す図にすぐ適用されます。白背景では、白、黄、淡い青などの明るい線は読みやすさを保つため自動で濃くなります。

## レイヤの順序（Data パネル）
- レイヤ左側の **⠿** を押したまま目的の位置へドラッグします（青い線がドロップ位置を示します）。または右側の **▲ ▼** で上下に移動。⋯ メニューには「Move to top／Move to bottom」もあります。順序はプロジェクトに保存されます。
- **Draw in layer order（既定でオン）** をオンにすると、一覧で上にあるレイヤほど手前に描かれます（点群、TIN、DEM、グリッドすべてに適用）。
  重なった部分では、下のレイヤが 3D で視点に近くても上のレイヤが覆います。同じレイヤ内は通常どおり 3D の深度に従います。オフにすると完全に 3D の深度で表示します。
- 編集がロックされているとき、断面には「一番上の表示中の点群」を使うため、順序を変えると断面に使う点群も変わります（断面は自動で再計算されます）。

## 再構成（Reconstruct メニュー）：写真測量、メッシュ化、モデル化

### Photos / Video → Point Cloud（Ctrl+Shift+P）
従来型の SfM-MVS（AI モデルは使いません）で写真や動画から色付き点群を作成します：特徴抽出（RootSIFT）→ マッチングと幾何検証（MAGSAC）→
逐次的な標定（PnP、三角測量）→ バンドル調整（焦点距離と放射歪み k1、k2 のセルフキャリブレーション）→ 位置合わせ → 密マッチング（SGBM＋左右整合性チェック）→ 多視点統合。

- **撮影のヒント**：前後のオーバーラップ ≥ 60 %（空撮では 70–80 % / 横方向 60 % を推奨）、テクスチャが明瞭なこと、同じ位置でその場回転しないこと。水面、ガラス、真っ白な壁はマッチングしにくい対象です。
- **動画**：一定の時間間隔ごとに最も鮮明なフレームを取ります（動きによるブレを自動で回避）。マッチングの既定は「Sequential」です。
- **焦点距離**：既定では EXIF（35 mm 換算焦点距離。調整の事前値として使用）を読みます。**鉛直空撮＋起伏の小さい地形では、焦点距離と飛行高度を区別できません**。
  写真に EXIF がない場合は焦点距離を手入力してください（mm＋センサー幅、またはピクセル）。
- **品質**：Low／Medium／High／Ultra で作業画像のサイズと特徴点数が決まり、Density で密点群の間隔が決まります。
  「Keep where seen by ≥ n pairs」はノイズ除去です（点が n 組の画像ペアに共通して支持される必要があります）。
- **位置合わせ（Georeferencing）**：
  - *Camera GPS*：EXIF の GPS で相似変換を行います（出力 EPSG の選択が必要）。民生用 GPS の精度はメートル級で、飛行経路が一直線だと回転が不安定になります（通知されます）。
  - *Ground control points*：基準点座標の CSV（名称, X, Y, Z）を読み込み、**Mark GCPs in Photos…** で見えている各写真上で中心をクリックします
    （ホイールでズーム、ドラッグでパン。1 点につき 2 枚以上、3 点以上）。マークは CSV に保存して次回読み込めます。一部の点を検証点（Check points）に指定できます。
  - *Level only*：位置合わせのデータがない場合は水平化のみを行います（空撮 nadir または地上手持ち upright）。座標はローカル座標で**縮尺はありません**。
- **出力**（Output フォルダ）：`*_dense.las`（RGB、views フィールド）、`*_sparse.las`、`*_cameras.csv`（X Y Z ω φ κ、f、k1、k2）、
  `*_report.json`（標定枚数、再投影誤差、位置合わせの残差）。結果は自動でプロジェクトに追加され、カメラ位置はベクタレイヤになります。

### Stereo Rig → Point Cloud（ステレオカメラ）
- 入力：左右 2 つのフォルダ、左右並びの写真、左右 2 本の動画、または左右並びの動画（左右のファイルはファイル名順で対応付け）。
- キャリブレーション：手動（焦点距離、主点、基線長。キャリブレーション済みのステレオカメラ向け）、キャリブレーションファイル（本プログラムの JSON または OpenCV の YAML / XML：K1 D1 K2 D2 R T）、
  またはチェッカーボードの写真（内側コーナー数とマスのサイズを入力。結果は JSON に保存）。
- 深さは基線長から直接換算するためメートル単位です。複数組の画像は左画像で SfM により連結し、縮尺は基線長で決まります。向きは「水平前方」「下向き」「カメラ座標」から選べます。

### Mesh from Point Cloud（Ctrl+Shift+M、任意の点群）
- **2.5D Delaunay**：地形、海底（平面位置ごとに 1 つの高さ）。最大辺長と間引きを設定できます。
- **3D alpha shape**：物体、構造物、ストックパイル。既定では半径を自動設定し内部の空洞を埋めて、閉じた外表面（体積計算可）を得ます。
- **Poisson／Ball pivoting**：Open3D のインストールが必要です（プログラムの依存パッケージ画面からインストール可能。パッケージ版には既定で含まれません）。
- 後処理：Taubin 平滑化、小さな断片の削除、簡略化（ボクセル統合）、点群の色の引き継ぎ。
- 書き出し：Data パネル ⋯ → Export… または Reconstruct → Export Mesh / Model…：OBJ（頂点色付き）、PLY、STL、DXF 3DFACE。
  座標が大きい場合はローカル原点で出力することもできます（オフセットはヘッダに記録）。

### 点群のモデル化（Model Planes／Cylinders／Buildings）
モデル化する点を先に選択（または分類で絞り込み）すると、結果も速度も良くなります。
- **Planes**：壁、屋根、床版、岩盤斜面、護岸 — 法線ベクトル、傾斜角／傾斜方向、面積、RMS。水平／鉛直／傾斜に限定できます。
- **Cylinders**：基礎杭、モノパイル、ポール、柱、パイプライン、樹幹 — 半径、長さ、軸方向、傾斜角、RMS。鉛直モードまたは任意方向。
- **Buildings**：事前に分類が必要です（Edit → Classify Points：地表 2、建物 6）— 建物の輪郭、地盤／軒／屋根の高さ、高さ、体積。
  LOD1 は単一の屋根高さの箱、LOD2 は屋根平面から屋根形状を作ります。輪郭はポリゴンレイヤとして別に保存されます。
- 結果は MSH データです：Data パネル ⋯ → **Mesh / model information…** でパラメータ表を表示します（行をダブルクリックするとそのモデルにズーム。CSV で書き出し可能）。
